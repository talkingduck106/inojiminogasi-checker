# 推し活チェッカー

＝LOVE・≠ME（あとで≒JOY）の**メディア出演**を、見た／見ないで消していくiPhone用Webアプリ。
ホーム画面に追加すると、独立したアプリとして開く。

## しくみ
- `scraper/scrape.mjs` … 公式サイトのスケジュールを読み、メディアだけを `data/data.json` に書き出す
- `.github/workflows/scrape.yml` … 上を毎日 5:17 と 0:17 に自動で実行し、アプリを公開し直す
- `index.html` / `app.js` / `app.css` … アプリの画面
- `config/members.json` … メンバー一覧（卒業・加入があったらここを直す）
- `config/programs.json` … 「第何回」を出したい番組の設定（初回の日付と休止週）
- 見た／見ないの記録は **iPhoneの中** に保存される（設定からバックアップを書き出せる）

## はじめにやること（PCで）
1. GitHubで新しいリポジトリを作る（名前は例：`oshi-checker`、**Public**）
2. 「uploading an existing file」から、このフォルダの中身をすべてドラッグしてアップロードし、Commit する
   - `.github` フォルダも忘れずに入れる
3. リポジトリの **Settings → Pages** で、Source を **GitHub Actions** にする
4. **Actions** タブ → 左の **update-data** → **Run workflow** を押す（数分かかる）
   - ログに「＝LOVE: 詳細 ◯件」「保存：メディア ◯件 / エラー ◯件」が出れば成功
   - エラーが多いときはログをClaudeに貼る
5. 終わると `https://（ユーザー名）.github.io/oshi-checker/` で開けるようになる

## iPhoneに入れる
1. Safariで上のURLを開く
2. 共有ボタン →「ホーム画面に追加」

## 画面
- 上：グループ（全グループ／＝LOVE／≠ME／≒JOY）→ メンバー → 媒体 で絞り込む
- 下のタブ：**今日**（今日の放送と、その下にカレンダー。日を押すとその日の一覧）／**見逃し**（今見られる・期限切れ。未消化の件数を表示）／**イベント**（チケット受付中・受付予定と、これからのライブ・リアル・オンライン・リリース）／**ガイド**（3グループの公式サイト、いこのいじょいchと各グループのYouTube、レギュラー番組の一覧）
- 予定をタップすると公式サイトのその予定のページが開く

## 操作
- 右にスワイプ＝見た、左にスワイプ＝見ない（どちらも ◯ と ••• からも同じことができる）
- 直後に出る「元に戻す」は、自分で閉じるまで残る。設定の「履歴」からも戻せる
- ••• →「iPhoneのカレンダーに追加」で、30分前通知つきの予定ファイル(.ics)を開く

## イベントのデータ
- ライブ・特典会・リリースは公式の「スケジュール」から、チケットの受付期間は「ニュース」記事から読み取る
- 第1次・第2次のように切れ目なく続く受付は1本にまとめ、1日以上あけば別に出す。入金期間・当落発表・物販は除く

## 見逃し期限のルール
| 媒体 | 期限 |
|---|---|
| 公式に「1週間」などの記載あり | その日数 |
| テレビ | 7日（TVer想定。公式に記載がなければ「見逃し不明・目安」） |
| ラジオ | 7日（radikoのタイムフリー） |
| SHOWROOM・ニコ生など | 放送終了まで |
| 雑誌 | 発売から30日 |
| YouTube・Prime Video など | 期限なし |
